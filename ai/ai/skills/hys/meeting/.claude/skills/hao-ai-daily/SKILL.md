# 豪豪 AI 日报

把散落在多个科技媒体的 AI 新闻，自动汇整成一份中文精华日报：一条资讯对应一张可点击的卡片，让用户用最少的时间掌握最新行业动态。

## 工作流程

按顺序完成四步：抓取 → 过滤 → 摘要 → 生成页面。

### 第 1 步：抓取原始资讯

运行本技能自带的抓取脚本，得到近 24 小时的原始新闻数据（JSON）：

```bash
python scripts/fetch_news.py
```

脚本会用 Python 标准库访问三个来源，无需安装任何依赖：
- **Hacker News**（Algolia API）——综合科技站，已按 AI 关键词 + 热度预筛
- **TechCrunch** AI 频道（RSS）
- **The Verge** AI 频道（Atom）

脚本输出到 stdout 的是一个 JSON 对象，结构为 `{"generated_at", "window_hours", "count", "items": [...]}`，其中每条 item 含 `title`（英文原题）、`url`、`source`、`published_at`、`points`。

如需调整时间窗口或条数，可用 `--hours`、`--max` 参数；默认近 24 小时、最多 40 条。若某个来源抓取失败，脚本会在 stderr 打 `[warn]` 并继续处理其余来源——只要还有至少一个来源成功，就照常往下走。

### 第 2 步：智能过滤

抓到的原始数据里有水分，需要你（而非脚本）做价值判断，只保留「值得关注」的行业资讯。过滤标准：

- **去重**：同一事件被多个来源报道时（如 "Amazon 用 Twitch 内容训练 AI" 同时出现在 HN 和 The Verge），只保留最有信息量的一条。
- **剔除噪音**：纯发布会预告/促销软文、与 AI 无实质关联的蹭热点内容、明显的水帖。
- **保留有价值**：新产品/模型发布、融资与并购、开源动态、研究突破、监管政策、行业争议与安全议题。

**优先级**：重大发布、大额融资、开源/研究突破 > 一般产品更新 > 边角资讯。目标产出 8–20 条精选；如果原始数据不足，有几条就展示几条，不要为了凑数硬塞。

### 第 3 步：生成中文摘要与标签

对每一条保留的资讯：

1. **中文标题**（`title_zh`）：把英文标题意译成简洁、准确的中文标题，不要逐字直译，去掉英文媒体常见的标题党语气。
2. **核心摘要**（`summary`）：50–100 字的中文要点，回答「这件事是什么、为什么重要」。用一句话讲清核心事实 + 一句点出价值/影响。不要复制英文标题的翻译腔，要用自然的中文行文。
3. **关键词标签**（`tags`）：2–4 个简短中文标签，方便快速定位。优先用领域通用词，如「大模型」「开源」「融资」「多模态」「AI 安全」「智能体」「监管」等，也可以带具体公司名（OpenAI、Google、Anthropic）或技术词（RAG、推理、扩散模型）。

### 第 4 步：生成可视化 HTML 日报

使用本技能自带的模板 `assets/template.html`，不要从零写 HTML。做法：

1. 读取 `assets/template.html`。
2. 把其中的 `__DATE__` 替换为当天的中文日期，格式如 `2026年8月13日`（取脚本输出里 `generated_at` 对应的本地日期，若无法确定时区就用当前系统日期）。
3. 把 `__NEWS_JSON__` 替换为一个 JSON 数组，数组元素字段如下（按此 schema 输出，模板的渲染脚本依赖这些字段名）：

```json
{
  "title": "英文原题",
  "title_zh": "中文标题",
  "url": "https://原文链接",
  "source": "Hacker News | TechCrunch | The Verge",
  "published_at": "ISO 时间",
  "points": 42,
  "summary": "50-100字中文摘要",
  "tags": ["大模型", "开源"]
}
```

   `points` 只有 Hacker News 有，其他来源填 0。
4. 把替换好的完整 HTML 写入一个文件，命名 `hao-ai-daily-YYYYMMDD.html`（日期用当天日期），保存到当前工作目录或用户指定位置。
5. 用一句话告诉用户文件已生成及保存路径，方便对方直接双击打开。

## 关键规则

1. **中文优先**：标题、摘要、标签都必须输出中文；仅当某条资讯的中文标题难以准确表达时才可保留英文关键词。
2. **摘要 50–100 字**：这是硬性区间，太长就精简、太短就补全价值点，不要写成一句话新闻搬运。
3. **卡片必须可点击**：每条资讯的 `url` 必须是真实可访问的原文链接，模板会自动把整张卡片做成跳转链接。
4. **忠实事实**：摘要只转述原文事实，不臆造数字、金额、人名；不确定的信息宁可省略。
5. **先抓取再总结**：不要凭记忆或 WebSearch 拼凑新闻，一律以脚本抓取到的数据为准。若脚本完全失败（三个来源全挂），如实告知用户网络/来源异常，而不是编造内容。
