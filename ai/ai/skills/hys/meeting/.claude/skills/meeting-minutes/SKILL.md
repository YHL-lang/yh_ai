# 会议纪要生成

把一段口语化、含大量停顿词和闲聊的会议文字稿，整理成一份结构清晰、可直接存档或分发的会议纪要。

## 工作流程

### 第 1 步：通读全文
先完整读完文字稿，理解会议主题、有哪些人发言、最终达成了什么结论。建立全局认识后再动笔，不要边读边写。

### 第 2 步：清理噪音
剔除与会议实质无关的内容，保留所有与决策、观点、事实、约定相关的信息：
- 停顿词、口头禅、重复（如"那那那""我我我""对对对""是吧"）
- 跑题闲聊、插科打诨、寒暄
- 语音识别产生的无意义乱码

### 第 3 步：按模板结构化输出

## 关键规则

1. **不确定即留空**：时间、地点、人名、金额等凡在文字稿中无法确定的信息，一律留空或标注"未提及"，绝不臆造、猜测或补全。
2. **忠实原文**：观点要忠实转述发言人的原意，不添加自己的解读或润色。
3. **行动项须三项齐全**：只有"谁 + 做什么 + 何时"都明确才算行动项；缺任一项就不强行写入行动项表，可并入会议内容。没有明确行动项时，表留空并说明。
4. **按主题不按顺序**：同一话题的发言合并到同一主题下，避免流水账。
