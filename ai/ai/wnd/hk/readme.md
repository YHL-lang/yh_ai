  ## prompt 设计过程
-创建一个网页来帮我写生日贺卡（Goal）
-当我提供一个人的姓名，年龄，爱好(Input)
-给我返回一条有趣的消息(Output)
-加上风格的标题和配色，使它好看些
-把卡片放在右侧，让它看起来像生日贺卡的内页 Layout
-在页面的顶部加一个有趣的标题。另外，不要替换掉原来卡片
-保留他们并叠放在新卡片下方。 Features 特点
 当我们用AI写代码时，不是随意去写prompt的，通常从一组基本指令开始
