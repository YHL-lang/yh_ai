## 数组的创建

- ADT 的认识
    连续的存储空间+特定的操作
- push，pop，shift，unshift
    - 修改原数组 破坏了原来的数组，这些方法都不是纯函数
    - push 返回结果是新长度 
    - pop 返回结果是移除的最后一个元素的值
    - unshift 在队头插入的元素的值，返回结果是新长度
    - shift 在队头出队元素 返回结果是出队的元素的值
- 纯函数  
- new Array(7)
指定了长度的空数组
[empty x 7] 初始化
empty 数组的这个位置还没有被占据 不属于任何类型
arr[0] undefined  
- (new Array(7)).fill(1)
[1, 1, 1, 1, 1, 1, 1] 
创建一个长度确定，同时每一个元素也确定的值的数组

## 遍历的方法
- for 计数循环
  机器化，命令式，缺点是可读性不好
  优点是性能最好
- for of
  语义很好 
- forEach
  入调用栈 执行上下文.... 
  优点是功能强大
  缺点是不能中途break;
- map、filter、every、some
  基于forEach实现
  返回结果是一个全新的数组(纯函数)
  filter 筛选 函数结果为true 留下
  every 每一项满足结果 true
  some 有一项返回true
