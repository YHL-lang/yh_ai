3.**文本特征**提取 
通过NLP 技术，将视频中的文本转换为向量
通过向量的语义分析，去判断视频的类型、内容、情感
4.**图片特征**提取 
通过图片识别技术，将视频中的图片转换为向量
通过向量的语义分析，去判断视频的类型、内容、情感

最终形成一个512维度的向量
