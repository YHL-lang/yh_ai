# 树和二叉树

数据结构的树，是对现实世界中树的一种简化。
- 树根 根节点
- 树枝 边
- 树枝的两端为节点
- 树叶抽象为叶子节点

倒过来思考，树的定义，就是从根节点开始，每个节点都有一个或多个子节点，直到到达叶子节点。

## 二叉树的定义

## 定义
- 它可以没有根节点，作为一颗空树存在。
- 如果不是空树，那必须由根节点、左子树和右子树三部分组成，且左右子树都是二叉树。

## 树的关键概念
- 树的层次计算规则
  根节点所在的那一层是第一层，其子节点在第二层，类推之。
- 树的高度
  叶子节点高度计为1，每向上一层高度+1，目标节点高度就是根节点到目标节点的路径长度。
- 度的概念
 一个节点开叉出去多少个子树，节点的度
- 叶子节点
  度为0的节点。 最后一层的节点都是叶子节点。
- 树的深度

二叉树不可以简单定义为每个节点的度为2的树。
左右子树的位置是严格约定，不能交换的。
