# JS 有多少种数据类型？
8 种数据类型
根据ECMA262 规范
primitive  原始数据类型有6种   Boolean String Null Undefined Symbol Numeric 其中Numeric 再分两种类型 Number 数值类型 和新增BigInt 大整数类型


## 简单数据类型
原始数据类型(primitive type)
- Number 数值类型
- Boolean 布尔值类型
- String 字符串类型
- Null 空值类型
  - 用于表示一个有意设置为空的对象引用(空的引用)
  - 表示某处应该有个值，不过目前没有(空的值)
  - 可用于清空一个变量的值，释放内存，垃圾回收

- Undefined 未定义类型
   表示一个未初始化 或不存在的变量值
  - 当声明一个变量但未赋值时
  - 某个对象属性不存在
  - 函数没有返回值时
  - 访问不存在的数组索引

es6 以前 js只有 6 种类型
### es6 新增数据类型
- Numeric 数值类型 内类 
  - Symbol 唯一  标识符类型
  - BigInt  大整数类型 

## 复杂数据类型
- object 对象类型
引用数据类型(内存分配)
