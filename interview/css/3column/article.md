# 📐 CSS 三列布局：从原理到实践

## 🎯 什么是三列布局？

三列布局是 **PC 端最常见的页面布局方案** 之一。它的核心特征是：

> 左右两列指定固定宽度，中间一列自适应宽度（占满剩余空间）

```
┌──────────┬─────────────────────┬──────────┐
│   Left   │     Main Content    │  Right   │
│  (固定)   │      (自适应)        │  (固定)   │
└──────────┴─────────────────────┴──────────┘
```

### 💡 为什么 Main 要放在最前面？

HTML 结构中，**Main 内容应该最先加载**。这样用户可以第一时间看到最核心的内容——左右两侧通常是广告、导航栏等辅助信息，可以稍后渲染。这是 **渐进增强** 的重要思想。

---

## 🧱 前置知识：BFC 是什么？

在学习三列布局之前，我们需要理解一个核心概念——**BFC**。

**BFC（Block Formatting Context）** 即 **块级格式化上下文**。

- 🌐 `<html>` 标签是根元素，它开启了第一个 BFC
- 📦 在 BFC 中，块级元素 **从上到下** 排列，行内元素 **从左到右** 排列——这就是最基本的 **文档流**
- 🔒 BFC 是一个 **独立的渲染区域**，内部的布局不会影响到外部

### 🚀 如何开启一个新的 BFC？

| 方式 | 说明 |
|------|------|
| `display: flex` | 弹性布局，开启 FFC（Flex Formatting Context） |
| `display: grid` | 网格布局，开启 GFC（Grid Formatting Context） |
| `display: table` | 表格布局 |
| `float: left / right` | 浮动布局 |
| `position: absolute / fixed` | 定位布局 |
| `overflow: hidden` | 溢出隐藏 |

> ⚠️ **关键理解**：外层 BFC 的格式化规则 **不会穿透** 内部新开辟的格式化上下文。这就是为什么我们能在局部区域用 Flex/Grid 实现不同的布局方式。

## 🛠️ 三种实现方案

### 方案一：Flex 弹性布局 ✅（推荐）

Flex 是现代布局的首选方案，代码简洁、语义清晰。

```html
<div class="layout">
  <aside class="left">Left</aside>
  <main class="main">Main Content</main>
  <aside class="right">Right</aside>
</div>
```

```css
.layout {
  display: flex; /* 开启新的格式化上下文 */
}

.left {
  width: 200px;   /* 固定宽度 */
}

.main {
  flex: 1;        /* 占满剩余空间 */
}

.right {
  width: 200px;   /* 固定宽度 */
}
```

**✨ 优点**：
- 代码最少，最容易理解
- 天然支持等高布局
- 响应式友好，可以轻松调整排列顺序

---

### 方案二：Grid 网格布局 ✅（最强大）

Grid 是专门为二维布局设计的方案，适合更复杂的场景。

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  /*  左固定  中间自适应  右固定  */
}
```

**✨ 优点**：
- 一行 CSS 搞定列定义
- `1fr` 语义明确：占剩余空间的一份
- 可以同时控制行和列（二维布局能力）

---

### 方案三：Float 浮动布局 ⚠️（传统方案）

Float 是早期的经典方案，理解它有助于读懂老项目代码。

```css
.left {
  float: left;
  width: 200px;
}

.right {
  float: right;
  width: 200px;
}

.main {
  margin-left: 200px;
  margin-right: 200px;
}
```

**⚠️ 注意**：
- 需要手动设置 `margin` 避免内容被遮挡
- 父元素需要清除浮动（clearfix）
- 不支持等高布局，容易出现高度塌陷问题

---

## 📊 三种方案对比

| 特性 | Flex | Grid | Float |
|------|------|------|-------|
| 代码简洁度 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |
| 浏览器兼容性 | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 等高布局 | ✅ 天然支持 | ✅ 天然支持 | ❌ 需额外处理 |
| 二维控制 | ❌ 仅一维 | ✅ 行+列 | ❌ |
| 适用场景 | 一维排列 | 复杂网格 | 老项目兼容 |

---

## 🎓 总结

```
三列布局 = 左右固定 + 中间自适应

核心思路：开启新的 BFC（格式化上下文）

  ┌─ Flex  → 最常用，一维排列首选
  ├─ Grid  → 最强大，二维布局首选
  └─ Float → 了解即可，老项目备用
```

**面试记忆口诀**：
> 三列布局不难记，左右固定中间移；
> Flex Grid 都能做，BFC 原理要牢记！ 🧠
